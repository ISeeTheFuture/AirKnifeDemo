# Air Knife System 이동 랙 분사 데모

실제 ToF 촬영에서 제품 후보를 고르고, 이 표면을 실은 가상 랙을 양측 로봇이 따라가는 과정을 시연한다. 기본 시나리오는 **촬영 세트 2, 속도 65 mm/s, 나이프 250 mm, 베이스 중심 간격 1,640 mm**다.

## Windows 배포본 실행

Windows x64에서 `release/AirKnifeDemo.exe`를 더블클릭한다. 실행 파일 하나에 Python, 촬영 세트 1~5의 XYZ 데이터, 양팔 시뮬레이션용 로봇 모델이 포함되어 있다. 업체 PC에 이 파일만 복사하면 된다. 실행할 때 임시 폴더에 구성 파일을 풀기 때문에 첫 화면이 열리기까지 잠시 걸린다. 다른 원본을 사용하려면 화면의 **원본 TAR 열기**를 선택한다.

### 배포본 다시 빌드하기

Windows x64에서 아래의 소스 실행용 환경을 활성화한 다음 프로젝트 루트에서 PowerShell로 실행한다. 원본 TAR는 사용자의 `Downloads` 또는 프로젝트 루트에 둔다. 다른 위치라면 마지막 명령 뒤에 `-- --tar "원본 TAR의 전체 경로"`를 붙인다.

```powershell
python -m pip install pyinstaller==6.22.3
python -m PyInstaller --distpath release --workpath "$env:TEMP\AirKnifeBuild" AirKnifeDemo.spec
```

## 소스 실행

1. 소스 ZIP을 한 폴더에 푼다.
2. 제공받은 `Air Knife System 검토 의뢰.tar`를 소스 폴더 또는 현재 사용자의 `Downloads`에 둔다. 다른 위치에서는 화면의 **원본 TAR 열기**로 선택한다. ZIP에는 촬영 원본이 들어 있지 않다.
3. 소스 폴더에서 아래 명령을 실행한다. 처음 환경을 만들 때 인터넷 연결이 필요하고 이후 시연은 로컬에서 실행된다. Windows에서는 conda-forge의 PyBullet 바이너리를 사용한다.

```shell
micromamba create -y -f environment.yml
micromamba run -n airknife-track2 python demo.py
```

Miniforge를 사용하는 PC에서는 다음 명령을 Miniforge Prompt에서 실행한다.

```shell
conda env create -f environment.yml
conda run -n airknife-track2 python demo.py
```

환경 도구 설치 안내는 [Micromamba 공식 문서](https://mamba.readthedocs.io/en/latest/installation/micromamba-installation.html)와 [Miniforge 공식 저장소](https://github.com/conda-forge/miniforge)에 있다.

## 업체 시연 순서

1. **촬영 데이터**에서 2번 샘플의 흰 관심 영역과 노란색 선택 표면을 확인한다. **원본 3D 점군**은 별도 Open3D 창에서 마우스로 회전·확대할 수 있다. 세트 2와 3의 폴더 이미지가 CSV의 형상과 교차하므로 화면은 CSV에서 직접 재구성한다.
2. 기본 배치는 한 줄당 2개씩 2줄이다. **촬영 세트** 아래에서 두 가지 방법으로 현재 배치를 바꿀 수 있다.
   - **격자 적용**은 입력한 열(한 줄당 제품 수)과 횡(줄 수)에 맞춰 제품을 등간격으로 놓는다. 예를 들어 3열 × 4횡을 적용하면 랙 한 면에 12개가 놓인다.
   - **랜덤 생성**은 **랜덤 총 개수**에 직접 입력한 수를 사용한다. 예를 들어 7을 입력하면 열·횡 설정과 관계없이 7개가 놓인다. 누를 때마다 제품이 들어갈 수 있는 범위에서 가로줄의 개수와 높이(Z)를 먼저 뽑는다. 같은 줄의 제품은 그 높이를 공유하며, 가로 위치(X)는 줄마다 독립적으로 뽑는다. 3D 랙과 피복 지도에서 생성된 가로줄을 확인할 수 있다. 두 방식 모두 실측 외곽을 기준으로 제품을 랙 안에 겹치지 않게 배치한다.
   - 속도·경로 변경, 처음으로, 경로 비교에는 현재 배치가 그대로 적용된다. 촬영 세트를 바꾸면 적용된 배치 방식과 개수를 기준으로 새 제품 크기에 맞춰 배치한다.
3. **분사 경로 · 누적시간 단축률 순**에서 방식을 고르고 **작업 셀 → 재생**을 누른다. 기본 선택은 가로 묶음 분사다. 전자동은 0순위, 수동 경로 7개는 우측에 적용한 종료·미리 이동 설정에서 전체 랙 왕복 대비 누적시간 단축률이 큰 순서로 표시된다. 성공 판은 작업시간, 실패 판은 20초로 합산한다. 항목에 마우스를 올리면 순위, 경로 설명, 전체 랙 왕복 대비 단축률과 단축 시간, 처리속도, 판 성공률이 표시된다. 촬영 세트 2의 제품 1~24개, 연속 5판 × 120묶음 기준이다. 청록색 선은 분사 경로다. 드래그로 회전하고 휠로 확대한다. 스페이스바는 재생·일시정지, 더블클릭은 기본 시점이다. [50개 전략의 실험 결과와 메뉴 순위](../docs/트랙2_연속5판_1-24개_전략비교.md)
4. 재생 중 **피복 지도**로 전환한다. 두 면의 표적 샘플은 노출 기준을 충족하면 황색에서 청록색으로 바뀐다. 두 로봇의 실제 공구 자세를 각각 사용한다.
5. **경로 비교**를 누르면 현재 샘플·배치·속도·공구 길이·베이스 간격을 사용해 일곱 고정 경로와 **전자동**을 실행한다. 각 방식의 작업시간, 도착 여유, 피복, IK, 접촉 차이를 비교한다.
6. 베이스 간격을 도면의 2,020 mm로 바꾸거나 1번 샘플을 선택해 다른 결과를 확인한다. 조건을 바꾸면 대기점부터 다시 시작한다. 단일 시나리오를 끝까지 재생하면 **결과 저장 (.md)**가 활성화된다. 비교 창에서도 Markdown으로 저장할 수 있다. 두 보고서에는 해당 배치의 제품별 가로 위치와 높이가 기록된다.

## 결과를 읽는 방법

### 연속 작업 설정

작업 화면 오른쪽의 **연속 작업 설정**에서 양팔의 시작 TCP, 판 종료 동작, 연속 판 수를 정한 뒤 **적용**을 누른다. **변경 취소**를 누르면 입력란이 마지막으로 적용한 값으로 돌아간다. XYZ는 mm 단위 월드 좌표다. X는 컨베이어 이송 방향, Z는 바닥에서의 높이, Y는 랙 중심에서 B면으로의 거리다. A면 로봇에는 Y 부호를 반대로 적용한다. 최초 설정은 1판, 시작 (0, 160, 980) mm, 시작 위치로 복귀다.

시뮬레이션을 처음 시작하거나 초기화하면 파란 B팔의 관절 자세를 주황 A팔의 시작 자세에서 랙 중심면을 기준으로 거울 대칭으로 계산한다. 연속 작업은 앞 판의 실제 관절 상태에서 이어진다. 벤치마크를 다시 실행할 때는 새 출력 폴더를 지정하면 기존 체크포인트와 구분해 측정할 수 있다.

**상·중·하**는 작업을 시작할 판에 제품이 놓인 줄을 기준으로 시작 Z를 정한다. **상**은 가장 높은 줄, **하**는 가장 낮은 줄, **중**은 두 줄의 중간 높이에서 가장 가까운 제품 줄이다. 거리가 같으면 높은 줄을 택하며 제품 줄이 하나뿐이면 세 선택의 높이가 같다. 화면의 Z 입력란에는 첫 판의 높이가 표시되고, 배치를 다시 생성하면 선택한 기준에 따라 값이 갱신된다. X·Y는 직접 지정한다. Z를 직접 편집하면 수동 높이로 전환된다. CLI에서는 `--start-level top`, `middle`, `bottom`으로 같은 기준을 선택한다.

| 매 판 종료 동작 | 마지막 분사 이후 |
| --- | --- |
| 시작 위치로 복귀 | 이격 후 설정한 시작 X·Y로 돌아간다. 상·중·하를 선택하면 다음에 시작할 판에서 같은 기준의 Z로 복귀한다. 마지막 판 종료 후에는 그 판의 시작 위치로 돌아간다. 수동 Z는 모든 판에 공통으로 적용된다. |
| 지정 위치로 이동 | 이격 후 별도로 입력한 종료 XYZ로 이동한다. 다음 판은 이곳에서 시작한다. |
| 마지막 분사 위치에서 계속 | 공기를 끈다. 다음 판 도착 전까지 아래의 미리 이동 설정을 적용하고, 도착 시점의 위치에서 다음 판의 경로를 시작한다. |

**다음 판 여유 시 미리 이동**은 **마지막 분사 위치에서 계속**을 선택했을 때 설정한다.

| 선택 | 다음 판 도착 전 양팔의 정렬 기준 |
| --- | --- |
| 빈칸 | 마지막 분사 위치에서 대기한다. |
| 상단 / 하단 | 월드 X·Y를 유지하고 다음 판의 가장 높은 / 낮은 제품 중심 높이 Z로 이동한다. |
| 좌우(상 우선) | 이송 방향(+X)의 맨 앞 제품이 판 도착 시 차지할 X·Z로 이동한다. 같은 선두 X에 제품이 여러 개면 가장 높은 제품을 택한다. |
| 좌우(하 우선) | 같은 선두 X에서 가장 낮은 제품을 택한다. 선두가 하나이면 두 좌우 옵션은 같은 동작이다. |

대기 이동 중에는 분사를 끄고 Y를 유지한다. 월드 좌표에서 490 mm/s로 이동하다가 목표에 먼저 닿으면 기다리고, 다음 판이 먼저 도착하면 그 시점의 위치에서 경로를 시작한다. 도착 기준은 랙 원점이 X = −340 mm를 지나는 시각이다. 이미 다음 판이 도착했거나 마지막 판이면 미리 이동을 생략한다. 정렬은 대기 자세를 정하며, 첫 분사 제품과 접근 방향은 선택한 분사 경로가 정한다.

**선두 제품 우선 분사**를 직접 선택하면 각 줄을 이송 방향 앞쪽(+X)과 뒤쪽 묶음으로 나눈다. 홀수 개인 줄은 앞쪽에 한 개 더 배정한다. 앞쪽 묶음들을 먼저 분사하고 후미 묶음들을 이어서 처리한다. 다음 판의 배치와 양팔 상태에 따라 줄 방문 순서와 좌우 분사 방향을 검증한다. 직접 선택하면 우측에서 지정한 종료 동작과 여유 시 미리 이동을 적용한다. 전자동에서도 동일한 방식이 다른 여섯 경로와 함께 경쟁한다. 명령줄에서는 `--mode leading`으로 실행한다.

촬영 세트 2의 4×4 격자 5판에서 상단 시작과 원위치 복귀를 지정하면 선두 제품 우선 분사는 5판 모두 통과했다. 컨베이어 65 mm/s, 나이프 250 mm, 로봇 베이스 간격 1,640 mm 조건이다. 이 격자에서 판별 작업시간을 합산한 결과, 전체 랙 왕복 대비 33.07% 단축됐다. 전체 랙 왕복은 5판 모두 실패해 100.00초(판당 20초), 선두 제품 우선 분사는 66.93초였다. 판 도착 대기를 포함한 선두 제품 우선 분사의 모의 경과시간은 74.31초였다.

**전자동**은 왼쪽 **분사 경로** 목록에서 선택한다. 시작 좌표, 제품 기준 시작 높이, 지정 종료 좌표와 판 수를 적용할 수 있다. 판별 종료 및 미리 이동 메뉴는 전자동이 맡는다. 현재 판에서 선택된 경로와 동작은 재생 화면에 표시되고, Markdown 보고서에는 모든 판의 선택이 남는다.

전자동은 **첫 판을 검증하면 재생할 수 있다.** 재생 중에는 현재 판의 예정 경로를 끝까지 실행했을 때의 양팔 관절 위치·속도와 컨베이어 시각을 이용해 바로 다음 한 판의 경로를 계산한다. 다음 판을 시작하면 그다음 판을 준비한다. 화면과 재생은 주 프로세스가 담당한다. 다음 판 검증은 첫 사용 시 시작되는 전용 프로세스에서 별도의 PyBullet 셀로 수행한다. 다시 시작하거나 비교 창을 열어도 같은 검증 프로세스를 사용한다. 판 전환 때에는 선택한 한 판의 경로와 인계 동작을 재생 중인 셀에 연결한다. 검증이 오래 걸리면 현재 판 작업 종료 프레임에서 재생 시계를 잠시 멈추고, 경로가 준비되는 대로 그 시점에서 이어간다.

작업 셀의 3D 화면은 재생 중에 CPU 렌더러로 최대 560 × 370 픽셀의 장면을 그려 창 크기에 맞게 확대한다. 그림자는 정지 화면에서 표시하며 이때 내부 해상도는 최대 850 × 560 픽셀이다. 분사 경로와 빔은 창 해상도로 덧그린다. 두 표시 모드 모두 같은 제품 형상, 60 Hz 제어와 240 Hz 접촉 검사를 사용한다.

각 판에서는 일곱 분사 방식과 종료 동작을 비교한다. 직전 판이 마지막 분사 위치에서 끝났고 도착까지 여유가 있으면 대기 중 정렬도 함께 비교한다. 인계와 해당 판의 도달·접촉·제품별 양면 피복 기준을 모두 통과하는 후보 중 가장 빨리 끝나는 경로를 선택한다. 모두 실패하면 해당 판에 가장 빠른 후보를 적용하고, 다음 판은 그 종료 상태에서 다시 검증한다. 판 사이의 IK 미달과 접촉은 실제 발생한 대기 구간을 기준으로 직전 판의 실행 통계에 기록한다. 묶음 성공률은 재생 결과로 계산한다.

물리 검증은 실시간 대기 없이 60 Hz 제어 프레임과 240 Hz 접촉 검사를 수행한다. 같은 인계 상태에서 여러 후보를 시험할 때에는 저장한 물리 상태를 복원한다. 같은 세션에서 로봇·공구와 랙 배치, 앞선 이동 이력, 현재 경로가 일치하면 최근 256개 판정에서 결과를 재사용한다. 데모에서는 다음 판 배치를 미리 안다고 가정한다. 실설비에는 상류 촬영 또는 판별 등록 데이터와 이송 동기화가 필요하다.

첫 판의 경로 후보는 양팔 관절이 목표에 도달할 수 있는지 최대 20초 구간씩 먼저 검사한다. 도달 가능한 후보는 모든 제어 프레임을 물리 시뮬레이션해 접촉과 제품별 분사 노출시간을 판정한다. 마지막 분사까지의 움직임이 같은 후보에서 종료 동작만 바뀌고 노출이 늘어날 수 없으면, 앞서 확인한 노출 부족 판정을 재사용한다. 후속 판의 관절 검사는 최대 10초 구간으로 진행한다.

**랜덤 총 개수**는 판 한 면당 제품 수다. 예를 들어 3판·7개로 생성하면 세 판에 각각 독립적으로 7개씩 배치한다. 격자를 적용하면 모든 판에 같은 격자가 놓인다. 처음으로, 경로 변경, 경로 비교는 같은 판별 배치를 사용한다. 3D 경로와 피복 지도는 현재 판을 표시하고 진행률과 전체 피복률은 묶음 전체 기준이다. 결과 Markdown에서 판별 작업시간, 최저 제품 면 피복률, 접촉과 도달 실패를 확인할 수 있다.

[기존 연속 3판 경로 비교](../docs/트랙2_연속3판_경로비교.md)는 고정 Z 1,150·840·530 mm로 수행한 실험이다.

[연속 5판 전략 비교](../docs/트랙2_연속5판_전략비교.md)에는 제품 1~30개에서 수동 42개 조합과 전자동을 같은 배치로 비교한 결과가 있다. 누적시간, 판 및 5판 성공률, 속도, 제품 수별 최단 기록과 전자동의 판별 선택을 확인할 수 있다.

완료 화면과 경로 비교에서 **처리속도(판/분)**는 처리한 판 수 × 60 ÷ 묶음 경과시간(초)이다. 판 사이 대기와 실패한 판의 작업시간도 포함한다. **판 성공률**은 이번 실행에서 도달·접촉·피복 기준을 모두 통과한 판의 비율이다. 세 판 중 두 판이 통과하면 화면에는 2/3 (66.7%)로 표시하고, 반복 실험 보고서의 **3판 성공률**에서는 해당 묶음을 실패 1건으로 센다.

### 지표

| 항목 | 계산과 범위 |
| --- | --- |
| 실제 촬영 | 5개 세트의 XYZ 축별 480행 × 640열 CSV를 직접 읽는다. 유한 XYZ와 양의 Z를 유지한다. 샘플별 수동 관심 영역에서 주변 배경 평면과 높이를 구하고 연결 성분을 거른다. Open3D 공분산과 주성분으로 가시 외곽·장축을 계산한다. 품번·나사·홈의 자동 인식은 검증 범위 밖이다. |
| 가상 현장 | 가시 표면을 700 × 1,100 mm 수직 랙에 지정한 개수만큼 배치한다. 반대면은 같은 측정 표면의 대칭 복제다. 트롤리 피치 990 mm, 일정 속도, 앞뒤 인접 랙을 가정한다. 실제 측정된 반대면이나 연속 랙 영상은 사용하지 않는다. |
| 로봇 및 공구 | PyBullet 배포판의 KUKA iiwa 7축 예시 모델 두 대를 사용한다. 베이스 높이 470 mm, 중심 간격 1,640 또는 2,020 mm다. 가상 공구는 질량 0.8 kg, 폭 40 mm, 깊이 70 mm의 단순 상자다. 실제 공구 하중·호스·작업 셀 보정은 별도 입력이 필요하다. |
| 경로 | 전체 랙 왕복은 유효 나이프 길이에 따라 랙을 행으로 나눈다. 표적 구간 분사는 실측 표적이 있는 높이와 가로 범위만 훑는다. 분사 속도는 320 mm/s, 비분사 이동은 490 mm/s, 계획 이격거리는 각 구간 최대 돌출면에서 42 mm다. 실기 SDK 연동은 포함하지 않는다. |
| 기하 피복 | 면별 선택 표면을 원본 영상의 3픽셀 간격으로 샘플링한다. 공구의 유효 길이 80%, 이동축 분사 폭 26 mm, 공구 앞 거리 25~85 mm, 명령 대비 자세오차 10° 이하에서 누적 25 ms 이상인 샘플 비율이다. 접촉이 기록된 제어 프레임은 제외한다. 샘플 밀도에 따른 근사치이며 유체·차폐·실제 잔류량은 모델링하지 않았다. |
| 도달과 추종 | 별도의 기구학 모델에서 관절 범위를 적용한 IK 해를 정기구학으로 다시 평가한다. 위치 오차 4 mm, 자세 오차 3° 이내를 충족으로 센다. 실제 TCP 추종오차는 물리 모델 관절 제어 결과에서 계산한다. 관절 속도 상한은 2.2 rad/s다. |
| 접촉 | 물리 계산 240 Hz, 제어·피복 계산 60 Hz다. 양팔·자기 충돌, 공구·랙·제품·주변 고정물 접촉을 검사한다. 인접 관절과 고정 베이스의 설치대 접촉은 제외한다. 제품 충돌체는 가시 형상을 감싼 보수적 상자다. 접촉 수는 **접촉이 있었던 60 Hz 프레임 수**이며, 서로 다른 사고 횟수를 뜻하지 않는다. |
| 간격·시간 | 로봇-랙 및 로봇 간 최근접 거리를 10 Hz로 확인하며 실제 관측 접촉도 반영한다. 간격 표시는 150 mm가 상한이다. 묶음 총시간에는 판 사이 도착 대기가 포함된다. 계획 여유는 `판 수 × 990 mm ÷ 이송속도 − 묶음 총시간`이다. 도달 실패나 충돌이 발생해도 진단을 위해 계획 끝까지 재생한다. |

이 시연은 학습 모델을 사용하지 않는다. 미리 지정한 관심 영역, 기하 계산, 물리 시뮬레이션을 사용한다. 실제 액체 제거 성능은 품종별 실물 분사시험으로 확인해야 한다.

## 창 없이 동일 조건 재현

```shell
micromamba run -n airknife-track2 python demo.py --headless --sample 2 --speed 65 --length 250 --mode target --report result.md
micromamba run -n airknife-track2 python demo.py --compare --sample 2 --report comparison.md
micromamba run -n airknife-track2 python demo.py --headless --mode horizontal --boards 3 --random-count 7 --seed 20261824 --start-xyz 0 160 840 --end-action point --end-xyz 0 200 900 --report three-boards.md
micromamba run -n airknife-track2 python demo.py --headless --boards 3 --random-count 7 --seed 20261824 --end-action continue --advance leading_top
micromamba run -n airknife-track2 python demo.py --headless --mode full_auto --boards 5 --random-count 7 --seed 20261824 --report five-auto.md
```

`--tar`로 TAR 경로를 직접 지정할 수 있다. `--base-mm`는 랙 중심에서 **한쪽** 로봇까지의 거리이므로 820 또는 1010을 입력한다. 화면에는 그 두 배인 베이스 중심 간격을 표시한다.
